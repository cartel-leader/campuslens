# 🔭 CampusLens — IIT Roorkee Student Productivity Hub

CampusLens is a web app built specifically for IIT Roorkee students to manage their academic life in one place.

## Features

- 📊 **Attendance Calculator** — Enter total and attended classes, instantly know if you can skip or need to attend more to stay above 75%
- 📝 **Assignment Tracker** — Add assignments with subject, deadline, and priority. Mark done, delete, sorted by deadline automatically
- 🤖 **AI Study Assistant** — AI powered chat to answer academic questions (coming soon)

## Tech Stack

- Next.js 14 (App Router)
- Tailwind CSS
- Claude AI API (Anthropic)

## Run Locally

npm install
npm run dev

Open http://localhost:3000
